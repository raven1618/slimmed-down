## 3. Delivery formats (decision S05: "fit to size, deliver in 4K")

| | Main screen | Sphere |
|---|---|---|
| Native LED canvas | 7296 × 1344 px (5.43:1) | 2688 × 1296 px reference |
| **Our delivery** | **3840 × 708 px**, same 5.43:1 ratio, 4K wide | **3840 × 1920 px** equirectangular (2:1) master + version converted to the controller's map |
| Safe area | Text and logos inside the visible die-cut zones. Center panel ≈ 1400 px wide at the top; a full-height 16:9 window ≈ 1259 × 708 | Content within ±30° of the equator; invisible seam; visible from all sides |
| Notes | The LED processor scales 3840 → 7296 (×1.9). Confirm the operator accepts this; a native 7296 × 1344 export is cheap to add if asked | Converting to 2688 × 1296 needs the supplier's mapping template (don't auto-stretch) |

Proposed for all files: **25 fps** (PAL region; confirm with the operator) · ProRes 422 HQ master + H.264 playback copy · stereo 48 kHz.
